## 已实测

### 2026-10-19 · Python 与脚本环境

- `D:\软件\Python\python.exe` 3.13；`zoneinfo` 的 `Asia/Shanghai` 可用。
- Windows 控制台默认 GBK：脚本输出中文/符号前需 `PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8`；脚本内 `sys.stdout.reconfigure(encoding="utf-8")` 生效。
- `python -m unittest discover -s tests` 在本工作区可跑（见建设期运行记录）；临时目录权限问题未出现。

### 2026-10-19 · 网页抓取（Palantir FDE 课题实测）

- Palantir 官方博客 `blog.palantir.com` 直接抓返回 403（Cloudflare 挑战）；用 `https://r.jina.ai/<原 URL>` 代理可拿到全文（Dev vs Delta、A Day in the Life of FDSE 均成功）。
- Palantir 官方文档 `palantir.com/docs/...` 可直抓，但页面含大量侧栏导航，返回内容很长且可能截断；关键段落通常在正文后段，需要定位。
- 招聘页 `jobs.lever.co/palantir/...` 直抓只能拿到标题；同样用 `r.jina.ai` 代理可取全文（岗位职责、薪资、地点）。
- Forbes 直抓 403；Fortune、36氪、腾讯云、YC、a16z 可直抓；FDE-Wiki 可直抓，但每页重复整份侧栏，正文有效信息约占三成。
- PDF（Palantir 10-K）`web_fetch` 返回 `unsupported content type "application/pdf"`；改用 StockAnalysis 的年报口径数据，并在台账标 B 级。
- 长页面会被截断，完整输出落到临时文件；本次未依赖截断部分下结论。

### 2026-10-19 · HTML 阅读效果

- 900px 桌面宽度：标题、结论卡、表格正常；L2 目录占据较高，已改为默认折叠的 `<details>`。
