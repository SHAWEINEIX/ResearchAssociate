SKILL.md 可靠性模式（[规范](https://mintlify.wiki/anthropics/skills/spec/overview)、[官方说明](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)）：

- name + description 必填；description 要「pushy」（做什么 + 何时用 + 触发词）。
- 三级渐进披露：元数据 → 正文 <500 行 → references/scripts 按需。
- 确定性计算交给脚本；正文命令式；输出模板写死。
- 附反模式清单 + rubric；每条 claim 要 URL + 时效 + 置信度；饱和即停。

研究子 agent 模板（[Claude Code subagents](https://code.claude.com/docs/en/sub-agents)）：Markdown + frontmatter，只给只读工具，只回摘要，并行拆独立子问题。

## 二、报告结构与框架

- 金字塔：结论先行、以上统下、同层 MECE；开场可用 [SCQA](https://managementconsulted.com/scqa-framework/)。
- 「So what」测试：每条发现后能接「所以呢、下一步做什么」，接不上就删。
- 执行摘要 = BLUF：1 页内结论 + 3 个数字 + 3 个动作 + 1 个反证。
- 每章第一行「本章要点」≤2 句。

| 问题 | 框架 | 必须产出 |
|---|---|---|
| 宏观/政策 | PESTEL | 哪 2 个变量真会变、影响谁 |
| 行业利润 | [五力](https://store.hbr.org/product/the-five-competitive-forces-that-shape-strategy/r0801e) | 哪股力在变、对谁有利 |
| 公司优劣 | SWOT + 价值链 | 优势来源与可维持性 |
| 市场大小 | [TAM/SAM/SOM](https://www.crv.com/content/how-investors-evaluate-market-size) | 两算交叉、区间 |
| 商业模式 | [BMC](https://www.strategyzer.com/) + 单位经济 | CAC/LTV/回本周期 |
| 需求 | [JTBD](https://store.hbr.org/product/know-your-customers-jobs-to-be-done/r1609d) | 真实替代品 |

证据分级：Tier 1 一手 → `[公开数据]`；Tier 2 权威二手 → 两源交叉 `[行业共识]`；Tier 3 自媒体 → 只做线索。时效：市场结构 >6 个月打折；具体数字 >18 个月不用。冲突并列，不悄悄选一个。

报告骨架：

- 尽调：[投资摘要与结论](https://magelegal.com/blog/how-to-write-a-due-diligence-memo) → 公司业务 → 行业竞争 → 财务 → 法律合规 → 风险 → 建议 → 附录。
- 竞品：[执行摘要](https://www.meltwater.com/en/blog/competitive-intelligence-report) → 格局 → 对手档案 → 功能/价格矩阵 → 定位 → win/loss → 动作。

失败模式 → 修法：

| 症状 | 修法 |
|---|---|
| 长而无洞察 | 每段问「删掉读者损失什么」 |
| 10 条并列发现 | 3 条主结论，其余降支撑 |
| 假精确 | 改区间 |
| 引用堆砌 | 一 claim 一 source，正文内联 |
| 通篇对冲 | 给方向 + 条件 + 失效条件 |
| 框架表演 | 结论落到数字或动作 |
| 摘要复述目录 | 摘要只写「所以怎么办」 |

## 三、中文报告惯例

- 券商研报骨架：封面/评级 → 投资要点 → 行业 → 公司 → 盈利预测与估值 → 催化剂与风险 → 附录；[SAC 规范](https://www.sac.net.cn/sjb/flfg_949/zlgz/202005/t20200525_14376.html) 要求数据核实、不传传言、披露评级、风险提示。
- 中文四件套：结论先行；数字带来源 + 时间 + 口径；事实判断分开；给动作。
- 政策解读：发文机关与文号 → 目标 → 工具 → 受影响主体与时间表 → 受益/受损 → 不确定性。
- 数据源：国家统计局、央行、海关、[巨潮](http://www.cninfo.com.cn/)、交易所、协会；艾瑞/QuestMobile/头豹/IDC 注意抽样与方法；36 氪/晚点/财新只作线索。
- 口径陷阱：现价/不变价、初步核算/最终核实、同比/环比；销量/销售额、出厂价/零售价、大陆/全球；报告发布日 ≠ 数据日。

## 四、最小可行规程（10 条）

1. 先写结论框，再写正文。
2. 问题拆 6–10 个互不重叠子问题。
3. 每条证据一行：claim / URL / 日期 / 置信度。
4. 关键数字至少两个独立来源；冲突并列。
5. 全文至少 5 条一手数据。
6. 每章开头两句话结论。
7. 超过 5 行的段落改表格或拆开。
8. 预测给区间、验证日期、失效条件。
9. 交付前跑反模式清单。
10. 中文稿补齐来源、口径、时间点、风险提示。
