# L0 快答（quick-answer.md）

> 一个问题、一个答案、几个来源。十分钟内给；不建课题，除非值得留档。

```json
{
  "key": "L0",
  "name": "快答",
  "max_chars": 300,
  "min_chars": 50,
  "min_sources_total": 1,
  "min_sources_a": 0,
  "required_sections": [],
  "conclusion_card_fields": [],
  "max_paragraph_lines": 5,
  "forbidden_patterns": ["综上所述", "由此可见", "赋能", "抓手", "闭环", "全面提升", "打造生态", "助力增长"]
}
```

## 结构

- 第一句：答案（数字/名单/判断）。
- 第二句：口径与时间（哪一年、什么范围）。
- 第三句：来源（机构 + 日期 + 链接），或「来源：E01」。
- 需要时补一句「不确定的地方」。

## 规则

- 答案必须能在第一句读完；不要先铺垫背景。
- 数字必须带口径；查不到就直说「没查到公开数据」，不猜。
- 来源只列实际打开的页面。
- 超过 300 字说明这不是快答，改走简报。

## 例子

> 2025 年中国企业 AI 培训市场规模约 120–135 亿元（艾瑞 2025-08，含企业内训与公开课，不含硬件）。口径差异：信通院口径约 110 亿元，差在是否计入政府补贴项目。来源：[E01][E02]
