# 跟踪更新（watch-update.md）

> 已有课题的增量更新：只写变了什么、意味着什么、要不要改结论。不重写旧报告。

```json
{
  "key": "WATCH",
  "name": "跟踪更新",
  "max_chars": 800,
  "min_chars": 100,
  "min_sources_total": 1,
  "min_sources_a": 0,
  "required_sections": ["变了什么", "对结论的影响"],
  "conclusion_card_fields": [],
  "max_paragraph_lines": 5,
  "forbidden_patterns": ["综上所述", "由此可见", "赋能", "抓手", "闭环"]
}
```

## 结构

```
# 课题名 · 更新 2026-10-19
## 变了什么
- 事实：…… [E12]（原 E04）
- 新增：……
## 对结论的影响
- 维持 / 调整 / 推翻；理由
## 下一步
```

## 规则

- 只写增量；旧结论用一句话引用，不复述全文。
- 每条变化带日期和来源；来源进课题台账，编号延续。
- 明确说「维持 / 调整 / 推翻」，不说「仍需观察」。
- 更新后同步改 `brief.md` 的「最后结论」和 `topics/index.md` 的状态。
- 连续 3 次更新都没有实质变化，建议停止跟踪或降频。

## 交付

对话里 3–5 行；需要留档时追加到课题 `log.md` 与 `report` 的更新记录。
