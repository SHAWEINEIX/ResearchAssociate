## 结构

```
# 对象名 · 尽调报告
> 日期 · L4 · 证据 N 条（A 级 M）· 用途

## 结论卡（建议合作 / 有条件合作 / 不建议；条件是什么）
## 红旗（按严重度排序，每条：事实、来源、影响、建议动作）
## 主体与资质（工商、股权、资质、处罚）
## 业务与客户（做什么、客户是谁、集中度、履约记录）
## 财务与履约（收入、现金流、合同、诉讼、被执行）
## 合规与诉讼（数据、资质、知识产权、劳动）
## 待核
## 来源
```

## 规则

- 红旗必须有事实和来源；不写「感觉不靠谱」。
- 主体信息以官方登记为准（国家企业信用信息公示系统、裁判文书、执行信息）。
- 财务数据只写公开可核的；未公开的不猜，写「未获取」。
- 人事、薪酬、合同金额标「敏感」，只写结论。
- 不替伭奥做交易决定；给「建议 + 条件 + 退出机制」。
- 涉诉、被执行、行政处罚：写案号/文号、时间、金额、状态。

## 交付

报告 + 红旗清单 + HTML；对话里先给红旗。
