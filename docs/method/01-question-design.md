# 提问与拆题（01）

> 研究做得好不好，一半在问题问得对不对。这一篇解决三件事：把模糊需求变成可回答的问题；把大问题拆成可取证的小问题；判断该做哪一档。

## 一、先判断这是不是「研究」

| 类型 | 例子 | 怎么做 |
|---|---|---|
| 查一个事实 | 「上海 2025 年办公楼空置率多少？」 | 快答 L0，一手来源 + 时间口径 |
| 比较几个对象 | 「这三家 AI 培训公司谁更适合企业采购？」 | 对标 L3，矩阵 + 结论 |
| 判断一个方向 | 「房地产 AI 应用未来两年有没有真需求？」 | 简报/专题，假设 + 证据 + 反证 |
| 评估一个政策 | 「这个团标对我们意味着什么？」 | 政策简报，原文 + 影响链 |
| 支持一个决定 | 「二期技能班定价定多少？」 | 专题，成本/竞品/支付意愿/风险 |
| 学习一个领域 | 「具身智能现在到哪一步了？」 | 简报，脉络 + 关键玩家 + 时间线 |

不是研究的：写稿、排期、找联系方式、做 PPT。转给对应 Agent，除非伭奥说「就在这里做」。

## 二、把问题问成「可回答」

一句话问题模板：

> **【对象】在【范围/时间】内的【什么】，是【哪一类答案：数字/排序/判断/时间表】？**

反例 → 改法：

| 模糊问法 | 问题在哪 | 改成 |
|---|---|---|
| 「研究一下 AI 培训市场」 | 没有对象、范围、用途 | 「面向房企中层的 AI 培训，2026 年上海地区的企业采购预算和主要供应商是谁？」 |
| 「房地产 AI 有没有前景」 | 「前景」不可证伪 | 「未来 12 个月，房企在 AI 上的支出会更集中在哪三类场景？依据是什么？」 |
| 「帮我看下这个政策」 | 没有读者和用途 | 「这份团标对我们在 10-24 发布的评估指南有什么影响？需要改哪几条？」 |
| 「竞品分析」 | 没有对象和维度 | 「技能班二期要对标的 3 家机构，在定价、课时、证书、获客上分别怎么做？」 |

三问自检：
1. 这个问题的答案能不能用一句话说出来？说不出来，继续拆。
2. 什么证据能证明答案是错的？说不出来，问题不可证伪。
3. 谁会反对这个答案？说不出来，可能问得太安全。

## 三、拆题

### 拆法

- **按决策链拆**：要不要做 → 谁付钱 → 付多少 → 谁能做 → 风险是什么。
- **按对象拆**：市场、客户、竞品、替代品、监管、技术。
- **按时间拆**：过去怎么发生 → 现在什么状态 → 未来 12–24 个月怎么变。
- **按利益相关者拆**（STORM 的视角法）：客户、供应商、监管、员工、投资人各自关心什么。

### 好子问题的标准

- 能独立找到证据；
- 能独立下一句判断；
- 和别的子问题不重叠；
- 合起来能回答主问题。

6–10 个为宜。少于 5 个通常漏了反面或约束；多于 12 个说明主问题没收敛。

### 假设先写

每个课题写 2–3 个假设，格式：

> H1：如果 ____，那么 ____ 应该出现 ____ 证据。
> H2：反方认为 ____；如果成立，会看到 ____。

假设的作用是防止「搜到什么写什么」。证据不支持就改假设，不硬圆。

### 定义「答完长什么样」

在 plan 里写清每个子问题的答案形态：

- 数字：需要哪个口径、哪一年、哪个地域。
- 排序：按什么排、权重是什么。
- 判断：支持/不支持/条件性支持，条件是什么。
- 时间表：关键节点、责任方、触发条件。

写不出答案形态，说明还没想清楚要什么。

## 四、范围

必须写清的四件事：

1. **时间**：数据截止到哪一天；预测到哪一年。
2. **地域**：全国 / 上海 / 一线城市 / 海外；口径是否可比。
3. **对象**：哪些客户、哪些竞品、哪些业态；明确不研究谁。
4. **深度**：L0–L4；体量上限。

范围写窄一点比写宽好。窄了可以补，宽了收不回来。

## 五、推荐深度

不确定时按这张表推荐，并说明理由；最终由伭奥定。

| 信号 | 推荐 |
|---|---|
| 一个事实、一个数字、一个名单 | L0 快答 |
| 要支持一次汇报、一个判断，1–2 页够用 | L1 简报 |
| 要拍板、涉及钱或人、结论会被质疑 | L2 专题 |
| 3 个以上对象要逐项比较 | L3 对标 |
| 合作方、供应商、投资对象 | L4 尽调 |

推荐话术（一次一条）：

> 这题我建议做**简报（L1）**：结论卡 + 2 页，半天内给。因为你要的是会上能用的判断，不是完整市场地图。要加到专题（L2）的话，我多做竞品和支付意愿两块，约 1–2 天。你定。

## 六、立项时不要做的事

- 不要在研究前就给结论方向（会污染取证）。
- 不要一次问超过 3 个问题；缺的按默认值先做，交付时说明用了哪条默认。
- 不要把「研究」当「找资料」；找资料不需要立项。
- 不要合并相似课题；先问是不是同一件。
- 不要承诺「全面」「所有」；承诺「够用来做这个决定」。
