# 红队复核（05）

> 自己写的东西自己夸，是模型最稳定的偏见。L2 专题及以上必须开一个**独立通道**：只给它 brief 和报告，不给研究过程、不给结论草稿、不给「请温和一点」。
> 红队的任务不是挑错字，是回答：一个聪明的怀疑者，会不会买这份结论？

## 一、什么时候做

| 档 | 是否红队 |
|---|---|
| L0 快答 | 不做，但自查引用 |
| L1 简报 | 可选；涉及钱、人、对外发布时做 |
| L2 专题 | 必做 |
| L3 对标 | 必做（重点查矩阵每格证据） |
| L4 尽调 | 必做（重点查红旗与反面） |

## 二、怎么开

1. 新开一个子 Agent，上下文干净。
2. 只给它：`brief.md`、`report-vN.md`、本文件。
3. 明确告诉它：不要改稿、不要写新版，只出复核意见。
4. 要求逐条判 pass/fail，不许打总分。
5. 结果落 `red-team-vN.md`，由主 Agent 逐条处理。

## 三、红队提示词（直接复制）

```
你是独立复核人。下面是一份研究报告和它的立项说明。你的任务不是润色，是判断这份报告能不能被一个聪明的怀疑者接受。

规则：
1. 只依据报告里的内容和它标注的来源判断；不要替它补资料，不要猜作者意图。
2. 逐条检查下面的清单，每条判 PASS 或 FAIL；FAIL 必须给：位置（哪一节/哪句）、问题、为什么是问题、怎么改。
3. 不打总分，不评「整体不错」，不说「建议进一步丰富」。
4. 如果报告结论站不住，直接说「结论不成立」，并给最强反方论证。
5. 如果报告没有致命问题，就说「未发现致命问题」；不要为了显得严格编问题。
6. 输出格式：
   ## 结论判定（成立 / 有条件成立 / 不成立）
   ## FAIL 清单（按严重度排序，最多 10 条）
   ## 我拿不准的（最多 3 条）
   ## 如果只改一处，改哪里

清单：
A. 结论
 A1 结论卡五件齐全（结论、3 个数字、3 个动作、反证、置信度）？
 A2 结论是判断，不是「情况复杂/机遇与挑战并存」？
 A3 反证条件具体、可验证？
B. 证据
 B1 每个数字有 [E##] 且编号能在来源表找到？
 B2 关键数字至少两个独立来源，或明确标「单源」？
 B3 有没有把搜索摘要、二手转述当原文？
 B4 有没有把不同口径混着比？
 B5 来源日期是否在有效期内？政策是否最新版本？
C. 推理
 C1 每个主结论有证据链，不是从常识跳过去？
 C2 有没有把相关当因果？
 C3 有没有忽略最强的反方论证？
 C4 二阶影响有没有考虑？
D. 范围
 D1 回答的是 brief 里的问题，不是另一个问题？
 D2 范围（时间、地域、对象）有没有偷偷扩大或缩小？
 D3 有没有超出证据能支撑的结论？
E. 可读性
 E1 结论卡能否独立读懂？
 E2 每节第一行是不是结论？
 E3 有没有长而无判断的段落？
 E4 读者看完知道下一步做什么吗？

报告：
<brief 全文>
<report 全文>
```

## 四、主 Agent 怎么处理

- 每条 FAIL：**接受并改**，或**不接受并写明理由**；不许沉默。
- 改完在 `red-team-vN.md` 记：编号、判定、处理（已改/不改+理由）、改在哪。
- 自查不算复核；没有独立通道就在交付里写「自评，可信度打折」。
- 红队说「不成立」但证据支持原结论：把反方论证写进报告「反方与风险」一节，不藏着。
- 红队说「不成立」且证据支持红队：改结论，不辩护。

## 五、主 Agent 自评 rubric（红队之外，自己过一遍）

每项 0/1，不打分，只找 0：

- [ ] 结论卡能独立读懂
- [ ] 三个数字是决定性的
- [ ] 每个数字有编号、来源、时间、口径
- [ ] 主结论有反方
- [ ] 待核/未获取写出来了
- [ ] 没有禁用套话
- [ ] 长度符合档位
- [ ] 一屏回执能说清「交了什么、结论、还差什么」

有两个以上 0，回炉，不交付。

## 六、红队常见误判

| 红队说 | 可能的情况 | 怎么处理 |
|---|---|---|
| 「证据不足」但没说缺什么 | 它没读到来源表 | 让它指出具体编号；仍不足就补 |
| 「结论太绝对」 | 反证条件没写清 | 补反证，不改方向 |
| 「建议补充更多数据」 | 无效意见 | 忽略，要求具体缺口 |
| 「整体不错」 | 无效复核 | 要求逐条 PASS/FAIL |
| 「结论不成立」但没给反方 | 无效复核 | 要求给最强反方论证 |
