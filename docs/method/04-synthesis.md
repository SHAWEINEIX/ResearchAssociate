# 成文与可读性（04）

> 报告不是研究过程的记录，是给读者做决定用的。读者只有几分钟：第一屏给结论，第一段给理由，后面才是证据。
> 这一篇管结构、语言、长度、排版，以及研究类文本的去 AI 味。

## 一、结构：结论先行

### 金字塔

1. 顶层：一句话结论（有方向、有判断）。
2. 第二层：3 条主论据（互相独立、合起来支撑结论）。
3. 第三层：每条论据下的证据（`[E##]`）、数据、案例。
4. 底层：口径、假设、待核、来源。

### SCQA 开场（可选，一段话）

- Situation：大家都知道的事实。
- Complication：变化或矛盾。
- Question：所以要回答什么。
- Answer：一句话结论。

不要写成四段；压成 3–4 句。

### 一屏结论卡（L1 以上必出）

```
结论：一句话，有方向、有判断。
关键数字：① ____ [E01]  ② ____ [E02]  ③ ____ [E03]
动作：① 谁 什么时候 做什么  ② ……  ③ ……
反证：若 ____ 成立，则本结论作废。
置信度：高 / 中 / 低 —— 因为 ____。
```

写卡的三条硬规则：

- 结论句里不能出现「可能」「或许」「有待观察」；不确定性放置信度和反证。
- 三个数字必须是**决定性的**，不是随便三个数。
- 动作要能执行；「建议关注」不算动作。

## 二、正文

- 按问题组织，不按「背景—现状—趋势—建议」套模板。
- 每节第一行是本节结论（≤2 句），后面才是论证。
- 小标题写结论，不写主题词：「A 类客户付费意愿高」优于「客户分析」。
- 一段 ≤5 行；一段只说一件事。
- 超过 3 项且要精确比对，用表格；表格紧跟引用它的段落。
- 因果、权衡、判断用文字，不硬做图；要做图就一图一个信息，标题写结论。
- 全部用「事实 / 推断 / 判断」标注；推断标「（推测）」。

### 推荐骨架（专题 L2）

```
# 题目（结论式）
> 日期 · 深度 · 证据数 · 一句话结论

## 结论卡
## 关键发现（3 条，每条：发现 → 证据 → 所以呢）
## 正文
### 1. 子问题一（标题即结论）
### 2. 子问题二
### ……
## 反方与风险（什么会推翻结论）
## 待核与未获取
## 口径与假设
## 来源（E 编号表）
```

简报 L1 砍到：结论卡 → 关键发现 → 2–3 节正文 → 待核 → 来源。

## 三、语言

### 用

- 短句；一句话一个意思。
- 动词开头：做、改、停、投、换、招。
- 具体名词和数字：「3 家」「12 个月」「客单价 2.8 万元」。
- 因果用「因为……所以……」，不用「随着……的推进，……不断深化」。
- 术语第一次出现给解释：「CAC（获客成本）」。
- 英文缩写保留，首次给中文。

### 不用

- 空话：进一步、不断、切实、扎实、有力、全面、深度赋能。
- 套话开头：随着……的不断发展、在当今……背景下、众所周知。
- 套话结尾：综上所述、由此可见、总而言之。
- 对冲：可能、或许、一定程度上、有待进一步观察（结论里不用；待核里可以）。
- 假精确：87.3%、提升 23.7%（没有来源就不写小数）。
- 自指：本文、本报告、笔者、我们（除非真代表团队）。
- 制作说明：本报告分为三部分、接下来将从……展开、数据来源于网络。
- 营销词：赋能、抓手、闭环、生态、护城河（除非引用原文并解释）。

### 中文报告四件套

1. 结论先行。
2. 每个数字带来源、时间、口径。
3. 事实与判断分开。
4. 给动作，不给「建议关注」。

## 四、长度

| 档 | 字数 | 删减顺序 |
|---|---|---|
| L0 | ≤300 | 只留答案 + 来源 |
| L1 | ≤1500 | 先删背景，再删重复，最后删形容词 |
| L2 | 4000–8000 | 先删与主结论无关的子问题，再删证据堆砌 |
| L3 | 矩阵 + ≤2000 结论 | 矩阵放附录，正文只留结论 |
| L4 | 按框架 | 细节进附录 |

超长时问：删掉这一段，读者会损失什么？答不上来就删。

## 五、去 AI 味（研究版）

研究文本的 AI 味不在词，在**没有判断**。以下是最常见的五种：

| 症状 | 例子 | 改法 |
|---|---|---|
| 三段式排比 | 「一是……二是……三是……」全是抽象名词 | 改成具体动作和时间 |
| 每段等长 | 五段各三行，像模板 | 重要的写长，不重要的写一句或删 |
| 只描述不判断 | 「市场规模持续扩大，竞争日益激烈」 | 给数字、给谁在赢、给我们的位置 |
| 过度 hedge | 「在一定程度上可能对……产生一定影响」 | 直接说影响谁、多大、什么时候 |
| 引用墙 | 文末 30 个链接，正文没有编号 | 正文内联 `[E##]`，文末只列用到的 |

正向做法：每段至少一个**只有这份研究才有**的事实、数字或判断。没有就删。

## 六、交付前语言自查

- [ ] 每节第一行是结论吗？
- [ ] 小标题是结论还是主题词？
- [ ] 有没有一段超过 5 行？
- [ ] 有没有连续三段都是「描述」没有「判断」？
- [ ] 有没有禁用词？
- [ ] 每个数字有 `[E##]` 吗？
- [ ] 读者只看结论卡和一屏，能不能做决定？
- [ ] 全文删掉 20%，信息有没有减少？没有减少说明本来就该删。
