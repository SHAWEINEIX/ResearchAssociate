# 伭奥定下的规则（memory/decisions.md）

> 只追加，不改写。格式：`| D-0xx | 日期 | 决定 | 来源 | 状态 |`。后面的规则推翻前面的，就追加新的一条并注明「取代 D-0xx」。
> 这些规则优先于 `docs/` 里的通用方法；冲突时以本文件和 `judgment.md` 为准。

## 当前有效摘要

- **交付**：一屏结论卡 + Markdown 报告 + 自动 HTML；结论先行，读完知道下一步（D-003、D-007）。
- **深度**：新课题没说深度时先问一次，给推荐档；不擅自定档（D-002）。
- **用途与领域**：判断/汇报底稿/对外素材/课程案例；行业市场、竞品对标、政策标准、技术选型、培训案例（D-004、D-005）。
- **证据**：一断言一来源、正文内联 `[E##]`、脚本校验；只引打开过的页面；数字带口径与时间（D-001、D-010、D-017）。
- **写法**：事实、推断、观点分开；禁用套话；不写制作说明；长不等于好（D-011、D-012）。
- **边界**：只写本 repo；邻仓只读；不对外发送；不替伭奥拍板（D-008、D-009）。
- **节奏**：暂时不挂定时；需要时他具体安排（D-006）。
- **记录**：每次交付更新课题台账、session-state、journal 并推送；更正分六类（D-013、D-014）。
