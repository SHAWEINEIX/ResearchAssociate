# sources · 信源台账

> 新信源第一次用就登记等级与坑；发现不可靠，追加一条并注明影响过哪个课题。等级：**A 一手**、**B 权威二手**、**C 线索**、**D 不可用**。台账按「机构」记，不按单篇文章记；单篇的引用进课题 `evidence.md`。

## 一手（A）

| 来源 | 覆盖 | 访问方式 | 已知的坑 |
|---|---|---|---|
| 国家统计局 data.stats.gov.cn | 宏观、人口、投资、消费 | 免费 | 现价/不变价、初步核算/最终核实要看清；区县数据滞后 |
| 住建部、地方住建委 | 房地产政策、预售、物业 | 免费 | 政策看原文与生效日，不看新闻解读 |
| 上海市经信委 / 发改委 | 产业专项、AI 政策、申报指南 | 免费 | 申报口径一年一变，用当年文件 |
| 中国房协 / 人工智能应用分会 | 团标、行业活动、会员动态 | 部分公开 | 协会口径偏行业倡导，不等于监管要求 |
| 巨潮资讯 cninfo.com.cn | A 股公告、财报、招股书 | 免费 | 港股/美股不覆盖 |
| 上市公司投资者关系页 / SEC EDGAR | 海外财报、电话会 | 免费 | 英文原文，注意财年口径 |
| 全国标准信息公共服务平台 | 国标、行标、团标 | 免费 | 团标在「全国团体标准信息平台」另查 |
| GitHub / 官方产品文档 | 技术选型、产品能力、定价 | 免费 | 文档会超前于实际功能，以实测为准 |
| arXiv / 期刊 / 会议论文 | 技术前沿、方法 | 免费/部分付费 | 预印本未经同行评审；引用写版本号与日期 |
| 企业官网定价页 / 招投标公告 | 价格、采购、履约 | 免费 | 官网价≠成交价；招投标看中标金额与条件 |

## 权威二手（B，需两源交叉）

| 来源 | 覆盖 | 访问方式 | 已知的坑 |
|---|---|---|---|
| 券商研报（中金、中信、华泰等） | 行业深度、公司研究、市场规模 | 多为付费/机构 | 有立场；预测部分标作者与日期 |
| 克而瑞 / 易居研究院 | 房地产销售、土地、城市数据 | 部分公开 | 口径与统计局不同，不能直接混用 |
| IDC / Gartner / Forrester | IT 与 AI 支出、市场份额 | 付费，摘要公开 | 摘要常缺方法学；全球口径≠中国口径 |
| 艾瑞 / QuestMobile / 易观 / 头豹 / 沙利文 | 中国互联网、AI 应用、用户 | 部分免费 | 抽样与推算多，必须看样本与方法；免费版常删方法学 |
| 中国信通院 / 赛迪 | 数字经济、AI 产业 | 免费报告 | 偏产业倡导，数据来源要回溯 |
| 36 氪 / 晚点 / 财新 / 界面 | 公司动态、融资、人事 | 部分付费 | 快但会更正；重要事实回溯原文或公告 |
| 头部咨询（麦肯锡、BCG、贝恩） | 趋势、案例 | 免费摘要 | 面向全球客户，落地性弱 |

## 线索（C，只作线索）

| 来源 | 用途 | 注意 |
|---|---|---|
| 微信公众号 / 知乎 / 小红书 / 抖音 | 找案例、找痛点、找从业者说法 | 不核实不引用；数字一律不用 |
| 行业峰会 PPT、公开课 | 找框架、找对标 | 营销成分高 |
| 聚合站、AI 生成摘要 | 快速了解轮廓 | 必须回溯原始来源，否则按 D 处理 |
| 天眼查 / 企查查 | 工商、司法、股权 | 信息有滞后；以官方登记为准 |

## 不可用（D）

- 营销稿、软文、无署名的「行业观察」。
- AI 生成且无原始出处的总结、榜单、数据。
- 无法追溯发布机构与日期的截图、转发。
- SEO 农场与内容聚合站。

## 检索与引用的实操

- 先中文后英文：政策与本地市场用中文一手；技术、海外对标用英文一手。
- 关键词组合：`对象 + 时间 + 口径`（如「长租公寓 AI 渗透率 2025 克而瑞」）；政策加 `文号`；公司加 `财报/电话会/招标`。
- 找到一篇好报告，先看它的**资料来源**，顺着找一手；不要直接引它的二手数字。
- 付费墙：能看摘要就标「仅摘要」；看不到正文不引具体数字。
- 记录：机构 + 标题 + 发布日期 + 数据口径 + URL，缺一不可。
