# sources · 信源台账

> 新信源第一次用就登记等级与坑；发现不可靠，追加一条并注明影响过哪个课题。等级：**A 一手**、**B 权威二手**、**C 线索**、**D 不可用**。台账按「机构」记，不按单篇文章记；单篇的引用进课题 `evidence.md`。

## 权威二手（B，需两源交叉）

| 来源 | 覆盖 | 访问方式 | 已知的坑 |

## 线索（C，只作线索）

| 来源 | 用途 | 注意 |
|---|---|---|
| 微信公众号 / 知乎 / 小红书 / 抖音 | 找案例、找痛点、找从业者说法 | 不核实不引用；数字一律不用 |
| 行业峰会 PPT、公开课 | 找框架、找对标 | 营销成分高 |
| 聚合站、AI 生成摘要 | 快速了解轮廓 | 必须回溯原始来源，否则按 D 处理 |
| 天眼查 / 企查查 | 工商、司法、股权 | 信息有滞后；以官方登记为准 |

## 不可用（D）

- 营销稿、软文、无署名的「行业观察」。
- AI 生成且无原始出处的总结、榜单、数据。
- 无法追溯发布机构与日期的截图、转发。
- SEO 农场与内容聚合站。

## 检索与引用的实操

- 先中文后英文：政策与本地市场用中文一手；技术、海外对标用英文一手。
- 关键词组合：`对象 + 时间 + 口径`（如「长租公寓 AI 渗透率 2025 克而瑞」）；政策加 `文号`；公司加 `财报/电话会/招标`。
- 找到一篇好报告，先看它的**资料来源**，顺着找一手；不要直接引它的二手数字。
- 付费墙：能看摘要就标「仅摘要」；看不到正文不引具体数字。
- 记录：机构 + 标题 + 发布日期 + 数据口径 + URL，缺一不可。
